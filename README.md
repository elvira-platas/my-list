# Мой список

Небольшой список задач для KDE Plasma и VR-режима KWin.

## Об авторстве

Проект создан по идее и запросу Elvira Platas для облегчения повседневной работы.

Исходный код этой версии сгенерирован и доработан с помощью OpenAI Codex (GPT-5) под руководством автора проекта.

## Возможности первой версии

- обычные задачи с чекбоксами;
- жирный и курсивный текст;
- размер шрифта от 8 до 72 pt;
- прозрачный фон для VR;
- автоматическое сохранение списка локально.

## Сборка

В этой папке выполнить:

```bash
qmake6 writer-todo.pro
make -j2
./writer-todo
```

Файл со списком сохраняется в каталоге данных приложения KDE.
